# Output files and formats

[Quick start](../README.md)

## Outputs

Suffixes below are appended to `-o`. Some are conditional on modes and stages.

| Suffix | Contents |
| --- | --- |
| `.args`, `.log` | Effective configuration and complete run archive |
| `.<segment>.tmpl.fasta` | Consensus template |
| `.pdr` | PDR placement |
| `.segment<N>.pdr<M>.pairs.tsv` | Candidate pair details |
| `.segment<N>.pdr<M>.pair-msa.tsv` | Alignment scores, ranks and retention |
| `.offtarget-amplicons.tsv` | Predicted products from paired background screening |
| `.pool<N>.kpartite.{nodes,edges,meta,allowed_pairs}.tsv` | Graph exports and current allowed combinations |
| `.pool<N>.dimer-methods.tsv` | Objective comparisons |
| `.pool<N>.<method>.primers.tsv` | Selected oligos by objective; compatible warm-start exports |
| `.landscape.svg`, `.pool<N>.landscape.tsv` | Combined landscape and counts |
| `.bed` | Final primer locations, sequences, pools and dimer annotations |
| `.bad-dimers.tsv`, `.dimer-summary.tsv` | Below-cutoff interactions and per-pool totals |
| `.coverage.tsv`, `.coverage.svg` | Coverage audit and final-panel visualization |
| `.variation.tsv` | Positional variation report |
| `.expansion.tsv`, `.pdr-windows.tsv` | Expansion audit and explicit final windows |
| `.before-expansion.*`, `.expanded.*` | Baseline and trial reports, where produced |
| `.expansion-comparison.svg` | Optional plot generated by `scripts/plot_pdr_expansion.py` |

The `.bed` file is a custom 12-column BED-like table with zero-based,
end-exclusive coordinates on the alignment-derived template:

1. Segment name
2. Start
3. End
4. Primer name
5. Pool number (occupies the standard BED score column)
6. Strand
7. Template-oriented primer sequence
8. Dimer status
9. Below-cutoff partner count
10. Worst below-cutoff energy
11. Annotation cutoff
12. Comma-separated partner names

Reverse-strand sequences are in template orientation; reverse-complement them
for synthesis orientation. These extra columns are not the standard BED12
schema. Use TSV headers to interpret reports. Dimer labels use the configured
cutoff, or −3000 cal/mol for non-cutoff objectives.
